## 2. Feature spaces and extraction details

### 2.1 Appearance features (`f_app`)

| Field | Value | Source |
| --- | --- | --- |
| coverage config alias | `dinov2_vitg14` | `src/configs/coverage_configs/coverage_faiss_dino_full_v2.yaml` |
| instantiated feature extractor | `facebook/dinov3-vit7b16-pretrain-lvd1689m` | `src/mmd/encoders.py`, `models/DinoV3/DinoV3.py` |
| spatial embedding layer | final transformer layer (`last_hidden_state`), keeping spatial tokens only after dropping the first 5 prefix tokens | `models/DinoV3/DinoV3.py` |
| resize size | `512` | `src/mmd/encoders.py`, `models/DinoV3/DinoV3.py` |
| image normalization | mean `[0.485, 0.456, 0.406]`, std `[0.229, 0.224, 0.225]` | `models/DinoV3/DinoV3.py` |
| prefix-token drop | first `5` tokens removed before keeping spatial tokens | `models/DinoV3/DinoV3.py` |
| patch grid / patch size | `32 x 32` tokens, implying `16 x 16` pixel patches at `512 x 512` input | derived from `vectors_per_image` in `src/configs/coverage_configs/coverage_faiss_dino_full_v2.yaml` and resize size in `models/DinoV3/DinoV3.py` |
| patch sampling | `1024` spatial tokens per image (`32 x 32` at `512 x 512`) | `src/configs/coverage_configs/coverage_faiss_dino_full_v2.yaml` |
| PCA reduction | output dim `256`, fit on `train`, max train vectors `500000`, whiten=`False`, L2 normalize=`True` | `src/configs/coverage_configs/coverage_faiss_dino_full_v2.yaml` |
| vector budget for coverage cache | max vectors `8000000` | `src/configs/coverage_configs/coverage_faiss_dino_full_v2.yaml` |

Note: the config label still says `dinov2_vitg14`, but the current implementation instantiates the DINOv3 HuggingFace checkpoint above. The supplement should document the implemented model, not just the alias.

The implemented appearance pipeline is:

1. Resize each RGB image to `512 x 512` and apply ImageNet normalization with the mean/std above.
2. Run the DINOv3 backbone and take `outputs.last_hidden_state`, then discard the first `5` prefix tokens so only spatial patch embeddings remain.
3. Treat the remaining `1024` spatial tokens as a `32 x 32` patch grid, with one embedding `z_p` per patch location `p`.
4. Fit PCA on training-split patch vectors only, using at most `500000` vectors, and project each raw token `z_p in R^D` to `256` dimensions.
5. L2-normalize the PCA output before downstream coverage or MMD calculations.

\[
\tilde{z}_p = W (z_p - \mu), \qquad W \in \mathbb{R}^{256 \times D},
\]

\[
f_{\mathrm{app}}(p) = \frac{\tilde{z}_p}{\lVert \tilde{z}_p \rVert_2}.
\]

## 3. Transfer estimator and leakage-free evaluation recipe

| Field | Value | Source |
| --- | --- | --- |
| estimator family | `ridge` | run metadata from `analysis_comprehensive_runs/ridge_resid_weighted_ridge_a10_no_family_no_density_zscore_zeroshot_v3/asym_and_mmd/run_metadata.json` |

| predictor standardization | `standardize=True`; intercept is kept unpenalized in `fit_linear_model` | `scripts/build_leakage_free_eval.py` and run metadata |
| target residualization | `cv_residualize_target_by_context=True`, context cols=`benchmark,model_family_encoder`, transform=`zscore`, eval space=`residual` | run metadata |
| fit weighting | `fit_sample_weighting=inverse_task`, `fit_balance_real_synth=True` | run metadata |
| aggregation | `overall_aggregation=macro_fold` | run metadata |
| pairwise context grouping | `pairwise_group_cols=benchmark,model_family_encoder` | run metadata and `scripts/build_leakage_free_eval.py` |

The ridge solver used in the leakage-free evaluator is

\[
\hat{\beta} = \arg\min_{\beta_0,\beta}\ \lVert y - \beta_0 \mathbf{1} - X\beta \rVert_2^2 + \lambda \lVert \beta \rVert_2^2,
\]

where predictors are optionally standardized fold-by-fold, and the intercept is excluded from the penalty matrix (`penalty[0,0]=0`).

Leakage prevention is implemented directly in the CV splits:

- Held-out training-dataset or benchmark protocols use `run_group_cv`, where each fold trains on rows outside the held-out group and tests only on the held-out group.
- Held-out `(train_dataset, benchmark)` joint protocols use `run_joint_ood_group_cv`, where training excludes any row sharing the held-out training dataset or the held-out benchmark, and testing uses only the held-out pair.
- The current evaluator does not perform an internal ridge-alpha grid search. `ridge_alpha` is supplied as a fixed CLI argument, and the final paper sweep scripts default it to `10`.
